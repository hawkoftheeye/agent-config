# Resonance Documentation Generator

Regenerates certain technical documentation files within the Resonance repository.

## Task

Within the /docs folder is a /prompts folder. This contains a series of documentation prompts - one per file - with the naming convention `description-of-task.prompt.md`. You are to read each prompt in turn and execute according to the instructions in the file.

- Each file will detail the exact file and location to output to - obey this exactly.
- As you work through each file, record your general progress to the terminal.
- Only use as input the exact files that the prompt details - do not deviate from this
- If anything is unclear or incomplete, say so.
